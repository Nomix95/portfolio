## Creating Missing Repos

If you don't have GitHub repos yet, create them:

1. Go to https://github.com/new
2. Repository name: Use the project name (lowercase, hyphens)
3. Description: Copy from portfolio
4. Public: Yes (to show on portfolio)
5. Add README.md
6. Copy the HTTPS URL
7. Paste into portfolio

---

## What If I Don't Have a Repo?

You have 2 options:

### Option A: Leave as `#`
```typescript
github: "#",  // Link won't be clickable
```

### Option B: Create Empty Repo
1. Create repo on GitHub
2. Add a README with project description
3. Link it in portfolio
4. Later: Add code to the repo
